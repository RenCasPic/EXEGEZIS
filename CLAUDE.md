# Reglas de trabajo en este repositorio

## Regla obligatoria (esta tarea y todas las siguientes)

**SIEMPRE haz commit y push después de CADA cambio. Sin excepciones.**

- No acumules trabajo sin commitear.
- Si te quedas sin límite o te bloqueas a medias, haz commit y push de lo que haya antes de parar.
- Cada commit se sube a GitHub (`git push`) en cuanto se hace, para que el trabajo no se quede solo en esta computadora.

## Instrucciones de terminal para René

Siempre en **CMD de Windows**, nunca PowerShell.
